1. 系统概述

本平台是面向中小型 IT 环境的资产与运维一体化管理系统，定位为 “记录 + 监控 + 流程 + 执行” 四位一体的运维工作台。系统采用 B/S 架构，Windows 服务器部署，浏览器访问即可完成日常运维工作。

核心能力
  • 资产管理 — 设备、资产、合同、软件许可、盘点、供应商、备件的全生命周期管理
  • 网络管理 — 子网、IP 地址、VLAN 统一规划与分配（IPAM），支持批量生成、导入导出、与设备联动
  • 监控管理 — 实时/历史性能采集（CPU、内存、磁盘、接口流量）、健康评分、SLA、趋势预测、异常检测
  • 拓扑管理 — LLDP/SNMP 自动发现、物理/逻辑拓扑、接口关系、机房 2D/3D 可视化
  • 运维管理 — 巡检、工单、变更审批、问题、知识库、服务目录、SLA 策略
  • 自动化执行 — 批量命令/脚本/配置下发，支持审批、定时、回滚、WebSSH、开放 API
  • 告警通知 — 规则告警 + 邮件/企业微信/钉钉/飞书/Slack/Webhook 多渠道推送
  • 报表合规 — 管理驾驶舱、标准报表、合规框架、报表分发、趋势预测
技术架构
  • 后端：Python Flask + SQLAlchemy；前端：Bootstrap 5 + jQuery；实时：Flask-SocketIO
  • 数据库：SQLite（默认）/ MySQL；缓存队列：Redis（可选）；定时任务：APScheduler
  • 采集协议：Ping、SNMP（v1/v2c/v3）、SSH（paramiko/netmiko）、WinRM、LLDP、WMI

2. 快速入门

2.1 登录与首次设置
  1. 浏览器访问系统地址，使用管理员分配的用户名/密码登录（默认管理员 admin，首次登录后请立即修改密码）。
  2. 进入 配置管理 → 系统设置，确认站点名称、时间区等基础参数。
  3. 进入 配置管理 → 用户管理 / 角色管理 / 权限设置，创建运维账号并按角色授权。
2.2 推荐的上线顺序
  1. 先建位置：位置管理 → 新增机房/位置，再新增机柜，录入 U 位信息。
  2. 再入设备：设备管理 → 添加设备或批量导入；网络设备建议配置 SSH/SNMP 凭据。
  3. 后做发现：拓扑管理 → 拓扑发现 / 设备发现，自动补全接口、链路与邻居关系。
  4. 规划网络：网络管理 → 先建 VLAN，再建子网（可勾选自动生成 IP），最后“从设备同步”自动标记已使用 IP。
  5. 开启监控：监控管理 → 监控设置，为设备启用 Ping/SNMP 采集，配置告警规则与通知渠道。
  6. 沉淀流程：运维管理 → 建立巡检模板、服务目录，配置变更审批（CAB）。
  7. 自动化提效：自动化 → 作业模板固化常用操作，再按需批量执行。
2.3 权限速查

管理员拥有全部权限；操作员可执行设备/监控/运维/网络/自动化等日常操作；普通用户与只读用户仅查看。具体见第 17 章。

3. 仪表盘

3.1 主仪表盘

登录首页展示：设备总数与在线/离线/告警统计、设备类型分布、位置分布、CPU/内存/磁盘趋势、最新告警、待办工单等。顶栏常驻在线/离线/告警计数，右侧显示我的待办工单角标。

3.2 相关看板入口
  • 综合报表 → 管理驾驶舱：全局业务视角看板。
  • 资产管理 → 资产驾驶舱：资产价值、折旧、合同到期等财务视角。
  • 监控管理 → 健康评分 / SLA 在线率：设备健康与可用性视角。
  • 自动化 → 执行概览：自动化任务成功率与执行统计。
  • 网络管理 → 网络概览：子网、VLAN、地址池分配率统计。

4. 位置与机柜

4.1 位置管理

位置用于描述机房、楼层、房间等物理场所。支持新增/编辑/删除、批量导入导出，字段包括地址、楼层、面积、容量、联系人、供电与制冷等。设备、机柜、子网均可关联位置。

4.2 机柜管理
  • 机柜关联位置，记录高度（U）、电源容量、尺寸等。
  • 机柜可视化：以 U 位视图展示设备占用，直观查看上下架与剩余空间。
  • 机房可视化 2D / 3D：机柜平面布局与 3D 立体视图，便于远程巡检。
4.3 使用建议

先建位置再建机柜，最后把设备放入机柜并填写 U 位与 U 高，即可自动统计机柜占用率。

5. 设备管理

5.1 设备列表与筛选

设备列表支持按类型、状态、位置、关键字筛选，可批量 Ping、批量删除、导出。点击设备名进入详情页，聚合展示基本信息、监控数据、接口、工单、变更、配置版本等。

5.2 添加 / 编辑设备

必填：名称（唯一）、IP 地址；推荐填写：类型、品牌型号、SNMP 团体字/版本、SSH 用户名/密码（自动化执行与配置获取需要）、位置机柜与 U 位。编辑页可同时维护接口、监控与凭据信息。

5.3 设备发现与导入
  • 设备发现：按 IP 段扫描在线设备并导入；网络设备可结合 SNMP/LLDP 发现接口与邻居。
  • 批量导入：下载 Excel 模板填写后上传，支持按 IP 范围展开；重复 IP/名称自动去重。
  • 批量导出：按当前筛选条件导出设备清单。
5.4 设备分组

分组支持树形层级与自动归类规则：按 IP 网段（如 192.168.1.）或名称模式（如 SW-%）自动把设备归入对应分组，也可手工归类。执行中心、报表可按分组选择目标。

5.5 下架管理

下架设备保留在“已下架设备”列表中，不参与监控与执行，便于追溯历史。

6. 拓扑管理

6.1 拓扑发现

通过 LLDP/SNMP 自动发现设备间连接关系；对不支持 LLDP 的设备可结合 ARP/MAC 表补齐末端设备（如 AP、打印机）。发现结果支持手动确认后入库。

6.2 连接关系与接口视图
  • 连接关系：管理设备-设备、端口-端口连接，标注链路类型、带宽、VLAN。
  • 接口视图：按设备查看接口状态、利用率、邻居，支持接口手工补录与调试。
6.3 拓扑图

物理拓扑按机房/机柜呈现设备连线；逻辑拓扑按业务域呈现。链路实时状态（在线/离线/降级）自动刷新，故障时高亮。

6.4 CMDB 依赖与影响

以设备/服务为节点展示依赖关系，变更前可评估影响范围，与变更管理联动。

7. 资产管理

7.1 资产清单与台账

资产覆盖服务器、网络设备、存储、办公设备等，记录资产编号、原值、净值、采购日期、保修期、负责人等；台账支持流水与状态变更留痕。

7.2 折旧计算

按资产类别设置折旧年限与残值率，自动计算每月/累计折旧与当前净值。

7.3 合同与软件许可

合同管理维护采购/维保合同，支持到期提醒；软件许可记录许可类型、数量、有效期，并可关联授权设备。

7.4 盘点

创建盘点任务，按位置/部门核对实物资产，差异自动生成报告；盘点记录可审计追溯。

7.5 供应商与备件
  • 供应商管理：供应商档案、联系人、供货记录。
  • 备件管理：备件库存、申请单、使用统计，支持入库/出库/预警。

8. 监控管理

8.1 采集与展示
  • 实时监控：设备 CPU/内存/磁盘/温度/电源状态实时刷新。
  • 性能图表：按设备/指标查看趋势曲线，可切换时间范围。
  • 接口监控：接口收发流量、带宽利用率、错误包统计。
  • 历史数据：按时间范围查询历史指标，支持导出。
8.2 监控设置

配置采集间隔、SNMP 超时/重试、监控启停；可按设备单独覆盖阈值与采集参数。

8.3 智能分析
  • 健康评分：综合可用性、性能、告警计算设备健康分，直观定位亚健康设备。
  • SLA 在线率：按设备/分组统计在线率，支持服务级别目标对比。
  • 趋势预测：基于历史数据预测资源耗尽时间（如磁盘、内存），提前扩容。
  • 异常检测：对指标突变自动标记异常，可与告警联动。
8.4 维护协同
  • 维护窗口：维护期间自动抑制相关告警，避免误报。
  • 告警升级：未处理的告警按策略升级通知到更高层级。
  • 事件关联规则：把根因告警与衍生告警归并，减少告警风暴。

9. 告警与通知

9.1 告警规则

支持按指标阈值（CPU、内存、磁盘、接口利用率、Ping 不可达等）创建规则，设定严重级别与生效时间。

9.2 告警处理

活动告警列表支持确认、关闭、备注；历史告警可查询与导出。告警升级策略可逐级通知。

9.3 通知渠道

在 配置管理 → 通知设置 中配置 SMTP 邮件、企业微信机器人、钉钉机器人、飞书机器人、Slack、通用 Webhook；自动化执行任务、告警、工单均复用这些渠道。

9.4 告警模板

通知标题与正文支持模板变量（设备名、IP、指标值、时间等），可按渠道分别定制。

10. 运维管理

10.1 巡检管理
  • 巡检模板：定义检查项（如设备灯状态、机房温湿度、告警核对）。
  • 巡检计划：按周期自动生成巡检任务并指派责任人。
  • 巡检任务/结果：逐项填写结果与备注，异常自动关联工单。
10.2 工单管理

支持创建/受理/流转/关闭工单，按服务目录分类，可关联设备与巡检问题；待办数量在顶栏角标提醒。工单可发起变更。

10.3 变更管理
  • 变更请求：描述变更内容、影响设备、实施计划与回退方案。
  • 变更日历/审批：变更窗口排期；按影响级别走 CAB 审批链。
  • CAB 配置：配置审批委员会成员、审批规则。
  • 变更影响分析：结合 CMDB 依赖评估受影响服务。
10.4 问题与知识
  • 问题管理：根因分析、已知错误登记、永久修复跟踪。
  • 知识库：沉淀解决方案，支持分类、搜索、维护权限控制。
  • 持续改进（CSI）：改进项登记与跟踪。
10.5 服务目录与 SLA

服务目录定义可申请的 IT 服务；SLA 策略设定响应/解决时限，工单超时自动升级并生成可用率报告。

11. 网络管理（IPAM）

11.1 网络概览

汇总子网数、VLAN 数、IP 总量与分配率，展示地址池状态和已分配最多的子网。

11.2 子网管理
  • 新增子网需填写名称、网络地址、前缀长度，可选网关、VLAN、位置、部门、标签；系统自动计算掩码、广播地址、可用主机数。
  • 自动检测与已有子网重叠，避免规划冲突。
  • 数据来源两种：① 手工输入；② 从设备分组或设备列表解析 IP，自动聚类出候选网段，选择后预填表单，再修改名称/备注保存。
  • 保存时可勾选“自动生成可用 IP”（排除网络/广播地址，上限 4096 个），或稍后在详情页点“生成IP”。
11.3 IP 地址管理
  • 状态：空闲 / 预留 / 已分配 / 禁用；可关联设备、主机名、MAC、使用人、部门。
  • 从设备同步：把设备库中落在该子网内的 IP 自动标记为“已分配”并关联设备。
  • 导入：Excel/CSV 或直接粘贴 IP 列表，按设备名称/IP 自动关联设备；导出支持当前筛选结果。
  • 释放 IP 一键恢复为空闲，删除/重复/跨网段均有校验。
11.4 VLAN 管理

维护 VLAN ID（1-4094）、名称、类型（业务/管理/互联/无线等）、网关、描述；子网可挂载到 VLAN，列表中可展开查看该 VLAN 下所有子网。已有子网的 VLAN 禁止删除。

12. 自动化执行中心

12.1 批量执行
  • 任务类型：命令执行（每行一条）、脚本执行（多行脚本）、配置下发（进入配置模式，华为系自动 save）。
  • 协议：自动判断 / SSH（Linux、通用）/ WinRM（Windows）/ Netmiko（网络设备）/ 本机执行。
  • 目标选择：手动选设备、按设备分组（含子分组）、按子网（IPAM 联动）、全部在线设备。
  • 每台设备结果（状态、输出、错误、耗时）独立保存，执行可随时取消，失败设备支持“重试失败”。
12.2 审批与安全

任务可标记“需要审批”，审批通过自动执行、驳回留痕；审批权限独立于执行权限（exec:approve）。建议对变更类/配置下发任务强制审批。

12.3 定时执行

支持间隔（如 5m / 1h / 1d）、Cron 表达式（如 0 3 * * *）、单次时间点；保存后即时注册进调度器，执行记录留档。

12.4 作业模板

把常用命令/脚本/配置保存为模板（含类型、协议、超时、默认审批），新建任务时一键带入，形成可复用的运维知识包。

12.5 配置下发与回滚

配置下发任务在执行前自动快照设备 running-config 并写入配置版本库；单台设备可一键“回滚”到执行前快照。

12.6 通知与审计

任务完成自动通知创建人（邮件 + 企业微信等已配置渠道）；所有创建/执行/审批/回滚动作写入审计日志。

12.7 前置条件
  • 网络设备：在设备上配置 SSH 用户名/密码或关联统一凭据。
  • Windows 主机：目标机启用 WinRM；服务端安装 pywinrm（本机可回退 PowerShell）。
  • Linux 主机：SSH 可达且有执行账号。

13. 在线终端（WebSSH）

通过浏览器直接打开设备的交互式 SSH 终端，无需本地安装 SSH 客户端，适合内网日常排障。

  • 入口：自动化 → 在线终端，选择设备后点击“连接”。
  • 凭据复用设备配置的 SSH 账号（或统一凭据），不在页面明文展示。
  • 支持窗口缩放自适应、复制粘贴、断开重连；会话实时加密传输。
  • 安全：需登录且拥有 exec:view 权限；匿名/无权限连接被拒绝。
建议仅在内网使用；如对外开放，请配合 HTTPS 与访问控制（VPN/防火墙）。

14. API 与令牌

14.1 API 令牌

在 自动化 → API令牌 生成令牌，分“只读”与“读写”两级；令牌明文仅创建时显示一次，支持停用/启用/删除，记录最后使用时间。

14.2 接口清单（/automation/api/v1/*）
方法路径说明权限
GET/devices查询设备（名称/IP/类型过滤）只读
GET/subnets查询子网及使用统计只读
GET/ips查询 IP 记录（按子网过滤）只读
GET/tasks查询执行任务只读
POST/tasks创建并执行任务读写
14.3 调用示例
curl -H "Authorization: Bearer <令牌>" http://your-host/automation/api/v1/devices
curl -X POST -H "Authorization: Bearer <令牌>" -H "Content-Type: application/json" \
  -d '{"name":"巡检脚本","device_ids":[1,2,3],"content":"df -h","task_type":"command","auto_run":true}' \
  http://your-host/automation/api/v1/tasks

鉴权方式：请求头 Authorization: Bearer <令牌> 或 X-API-Key: <令牌>。

15. 综合报表

15.1 管理驾驶舱与仪表板

管理驾驶舱提供全局运营视图；仪表板管理支持自定义看板，可把常用报表组件固定到首页。

15.2 标准报表
  • 综合报表：设备/资产/告警/工单全量汇总。
  • 统计图表：按类型、状态、位置的分布图。
  • 报表导出：按模板导出 Excel/PDF/CSV。
15.3 服务与合规
  • 服务 SLA 报表：工单/变更的时限达成率；真实可用率报表。
  • 服务满意度（CSAT）：工单闭环后的满意度评分。
  • 合规管理：合规框架、证据、报告，支持 ISO27001/SOX 等场景。
15.4 分发与预测

报表分发支持按计划推送邮件/渠道；趋势预测基于历史数据预测设备增长、容量趋势。

16. 配置管理

16.1 系统配置
  • 系统设置：站点名称、扫描间隔、SNMP 默认参数等。
  • 全局参数：业务级参数统一维护。
  • 备份与恢复 / 备份验证：数据库与配置备份，支持计划备份与验证。
16.2 配置合规
  • 合规策略：按类别（安全/网络/系统）定义检查规则。
  • 执行检查 / 合规报告：批量检查设备配置并出报告。
  • 配置基线：保存基线并检测漂移，漂移监控页面展示差异。
  • 配置版本：设备配置历史版本，支持对比与回滚素材。
16.3 告警与通知配置

告警模板、通知设置（SMTP/企微/钉钉/飞书/Slack/Webhook）、通知模板、升级策略统一在此维护。

16.4 网络与发现配置
  • SNMP 设置：团体字、版本、超时重试。
  • 凭据管理：统一凭据（SSH/WinRM/SNMP）加密存储，设备可引用；自动化执行与配置获取优先使用。
  • 发现配置：默认扫描范围、协议开关、自动导入策略。
16.5 用户与权限

用户管理、角色管理、权限设置三位一体：角色绑定权限集合，用户绑定角色，页面菜单与按钮按权限自动显隐。

16.6 日志

系统日志（运行/操作）、审计日志（登录、增删改、执行、审批）、日志设置（轮转与保留）统一管理。

16.7 系统定时任务

查看/启停系统内置任务（设备检测、指标采集、拓扑发现、链路监控、SLA 计算、数据清理等）。

17. 权限与角色

系统内置四类角色，均可在权限设置中调整；管理员默认拥有全部权限。

角色说明典型权限
admin系统管理员全部模块查看与编辑、系统配置、权限管理、任务审批
operator操作员设备/监控/运维/网络/自动化查看与编辑、执行与审批、报表
user普通用户大部分模块查看、设备编辑、运维工单处理、执行查看
viewer只读用户各模块查看与报表查看

关键权限码示例：device:view/edit、monitor:view/edit、network:view/edit、exec:view/run/approve、maintenance:view/edit、config:view/edit 等。自动化执行属高危能力，建议仅授予管理员与操作员。

18. 部署、运维与安全

18.1 部署形态
  • 开发/测试：python app.py（默认 127.0.0.1:5000，自动建表、初始化管理员）。
  • 生产（Windows 推荐）：waitress-serve --host=0.0.0.0 --port=8000 wsgi:application，可用 NSSM 注册为 Windows 服务。
  • 数据库默认 SQLite（单机），数据量大时通过 DATABASE_URL 切换 MySQL。
18.2 初始化与升级

首次启动自动创建数据表并写入默认管理员（admin/admin123，请立即修改）与角色权限；新增模块的表在重启时自动创建，无需手工迁移。升级前请先备份。

18.3 备份策略

定期备份数据库文件（SQLite 可在线备份 WAL 模式；MySQL 使用 mysqldump）与 uploads/ 目录；可在系统内配置备份计划与验证。

18.4 安全建议
  • 生产环境必须修改默认口令、使用 HTTPS；不要在公网直接开放。
  • WebSSH、批量执行、凭据管理属高危功能，严格按角色授权并保留审计日志。
  • SNMP 避免使用 public 团体字，凭据使用系统统一凭据库加密存储。
  • 日志建议按合规要求轮转与异地归档。
18.5 依赖说明

WebSSH 页面依赖 CDN 上的 xterm.js 与 socket.io；内网离线部署时请将对应静态文件下载到本地 static 目录。Windows 远程执行需目标机启用 WinRM 并安装 pywinrm。

19. 常见问题

Q1：设备扫不到 / 拓扑发现为空？

检查设备是否在线、SNMP 团体字与版本是否配置正确、防火墙是否放行 UDP 161/162；LLDP 需在交换机开启并允许网管获取。

Q2：监控无数据？

确认设备已启用监控、SNMP 可通、采集间隔合理；查看系统日志定位超时或认证失败原因。

Q3：批量执行提示“未配置 SSH 凭据”？

在设备编辑中填写 SSH 用户名/密码，或到配置管理 → 凭据管理创建统一凭据并关联设备。

Q4：Windows 主机执行失败？

目标机执行 Enable-PSRemoting 启用 WinRM，并确认服务端已安装 pywinrm；本机（127.0.0.1）可自动回退 PowerShell。

Q5：子网生成 IP 数量超限？

为防数据膨胀，单次自动生成上限 4096 个；更大网段建议拆分规划或按需手工录入。

Q6：WebSSH 无法连接？

确认设备有 SSH 服务与凭据、页面可加载 xterm.js（内网需本地化静态资源）、当前账号有 exec:view 权限。

Q7：告警没收到通知？

检查通知设置（SMTP/机器人 Webhook）是否填写正确、告警规则是否启用、维护窗口是否命中。

Q8：忘记管理员密码？

可进入数据库将 admin 用户密码重置，或联系开发支持；日常建议通过角色管理配置备用管理员账号。
