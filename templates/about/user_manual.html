1. 系统概述

网络资产管理系统是一套面向企业IT基础设施的综合管理平台，涵盖设备发现与登记、实时监控、告警管理、网络拓扑可视化、运维工单、资产全生命周期管理及报表分析等核心功能。系统采用 B/S 架构，通过浏览器即可完成所有操作。

核心能力
  • 设备管理 — 网络设备的发现、登记、编辑、批量导入导出
  • 监控管理 — 实时性能数据采集（CPU、内存、磁盘、网络）、健康评分、SLA在线率
  • 告警管理 — 告警规则配置、通知推送（邮件/微信/Slack/Webhook）
  • 拓扑管理 — 物理拓扑与逻辑拓扑自动发现、连接关系管理
  • 运维管理 — 巡检任务、工单流转、变更管理、问题管理、知识库
  • 资产管理 — 资产台账、合同管理、软件许可、资产盘点、供应商管理、备件管理
  • 报表中心 — 综合报表、合规管理、报表分发、趋势预测

2. 快速入门

2.1 登录系统

打开浏览器访问系统地址，使用管理员分配的用户名和密码登录。首次登录后建议在个人设置中修改密码。

2.2 设备发现
  1. 导航至 设备管理 → 设备列表 → 网络扫描
  2. 输入 IP 地址段（如 192.168.1.0/24），点击扫描
  3. 扫描完成后可选择将发现的设备导入系统
  4. 也可以通过 批量导入 上传 Excel 模板批量创建设备
2.3 配置监控
  1. 进入 监控管理 → 监控配置，为设备启用 Ping 或 SNMP 采集
  2. 系统将自动按周期采集设备的 CPU、内存、磁盘等指标
  3. 在 实时监控 页面查看各设备的实时数据
2.4 设置告警
  1. 进入 配置管理 → 告警设置，配置 SMTP 邮箱或 Webhook 等通知渠道
  2. 在 告警管理 → 告警规则 中创建告警规则，设定阈值
  3. 当监控指标触发阈值时将自动发送通知

3. 仪表盘

3.1 主仪表盘

登录后首页为主仪表盘，展示：设备总数及在线/离线统计、告警概览、CPU/内存/磁盘使用率趋势图、网络吞吐量、设备状态分布、最新告警列表、设备健康评分分布。

3.2 管理驾驶舱

导航至 综合报表 → 管理驾驶舱，提供全局业务视角的数据看板。

3.3 监控管理仪表板

导航至 监控管理 → 管理仪表板，查看监控覆盖率、健康评分统计、维护窗口状态等。

4. 设备管理

4.1 设备列表

展示所有已登记设备，支持按类型、状态、位置等条件筛选，可自定义列显示。点击设备名称进入详情页。

4.2 添加/编辑设备

支持手动添加单个设备，填写设备名称、IP 地址、设备类型、厂商型号、位置归属、SNMP 团体字等字段。编辑时还可修改监控配置和接口信息。

4.3 批量操作
  • 批量导入 — 下载 Excel 模板，按格式填写后上传，支持 IP 范围自动生成
  • 批量导出 — 将设备列表导出为 CSV 文件
  • 批量删除 — 选择多个设备后批量删除
  • 批量 Ping — 批量检测设备连通性
4.4 网络扫描

输入 IP 范围进行网络扫描，自动识别在线设备及其开放端口、MAC 地址等信息。扫描结果可选择导入到设备列表中。

4.5 设备详情

设备详情页聚合展示：基本信息、监控数据（实时及历史）、接口列表、关联工单、变更记录、配置基线、配置版本历史等。

5. 资产管理

5.1 资产库存/台账

管理企业所有IT资产（含网络设备、服务器、存储等）。资产卡片记录资产编号、名称、类别、采购信息、财务信息（原值、残值、当前净值）、位置归属等。

5.2 资产全生命周期
  • 入库登记 — 添加新资产，录入采购日期、供应商、质保期
  • 状态变更 — 在库、领用、维修、报废等状态流转
  • 折旧计算 — 支持直线法/双倍余额递减法折旧，自动计算当前净值
5.3 合同管理

管理采购合同、维保合同等，跟踪合同金额、生效日期、到期提醒。支持合同附件上传。

5.4 软件许可管理

记录软件许可证的购买数量、已分配数量，支持许可证的分配/回收操作，跟踪许可证到期时间。

5.5 资产盘点

创建盘点任务，选择盘点范围（按位置/部门），系统自动生成盘点明细。现场扫描或录入盘点结果（一致/差异/缺失/损坏），自动生成盘点报告。

5.6 供应商与备件管理

管理供应商信息、联系方式、供货范围。管理备件库存的入库/出库/使用记录，支持备件申请审批流程。

6. 位置与机柜管理

6.1 位置管理

按机房/楼层/区域组织位置层级，支持导入导出。机房可视化页面以 2D/3D 视图展示设备分布。

6.2 机柜管理

管理机柜的 U 位分配，机架视图直观展示每个 U 位的设备占用情况。支持拖拽调整设备在机柜中的位置，可视化展示设备在机柜中的安装布局。

7. 监控管理

7.1 实时监控

以卡片列表展示所有设备的实时运行状态，包括 CPU 使用率、内存使用率、磁盘使用率、网络流量、温度、在线时长等指标。状态通过颜色标识（正常/警告/危险）。

7.2 性能图表

选择设备和指标后，以折线图展示历史性能趋势，支持按时间范围筛选。

7.3 设备状态总览

以表格形式汇总所有设备的最新监控数据，支持排序和筛选，便于快速定位异常设备。

7.4 健康评分

基于监控数据自动计算各设备的健康评分（0-100分），综合 CPU、内存、磁盘、网络、Ping 五项指标。支持按评分分布统计，快速识别亚健康设备。

7.5 SLA 在线率

基于实际的 MonitorData 记录计算设备在线率（月度/季度/年度），统计平均在线率、低于 SLA 阈值的设备数及总宕机时间。

7.6 维护窗口

创建维护窗口，设定受影响的设备及时间范围，维护期间自动抑制相关告警。

7.7 异常检测

配置异常检测规则，系统通过统计偏差等方法自动识别指标异常，支持灵敏度调节。

7.8 趋势预测

基于历史监控数据，按天聚合指标均值，生成未来 7 天的趋势预测（含简单线性趋势）。

7.9 告警升级策略

设置多级告警升级策略，当告警持续未处理时自动通知更高级别负责人。

8. 告警管理

8.1 告警列表与活跃告警

展示系统产生的所有告警，支持按级别（紧急/高/中/低）、状态（活跃/已确认/已解决）、时间范围筛选。活跃告警视图聚焦当前未处理的告警。

8.2 告警规则

创建告警规则：选择指标（CPU/内存/磁盘等）、设定比较运算符和阈值、持续时间。支持批量启用/禁用规则。

8.3 通知设置

配置告警通知渠道及接收人。支持多种通知方式：邮件（SMTP）、企业微信机器人、Slack 机器人、通用 Webhook。通知内容支持自定义模板。

8.4 告警确认与处理

支持单条或批量确认告警、解决告警，记录处理人及处理时间。

9. 拓扑管理

9.1 物理拓扑

以图形化方式展示网络设备的物理连接关系，支持拖拽布局、自动排列，设备状态通过颜色实时反映。

9.2 逻辑拓扑

以逻辑视角展示网络分层结构（核心层/汇聚层/接入层），便于理解网络架构。

9.3 自动发现

通过 LLDP/CDP 协议自动发现网络设备间的互联关系，支持手动添加连接。

9.4 连接关系管理

以表格形式管理设备间的连接，支持添加/编辑/删除连接，查看连接详情（两端设备、接口、带宽等）。

9.5 接口管理

管理设备接口信息（名称、类型、状态、速率），支持 SNMP 自动发现接口。

10. 运维管理

10.1 巡检管理
  • 巡检模板 — 创建巡检模板，定义检查项目列表（日检/周检/月检等）
  • 巡检任务 — 基于模板创建巡检任务，指派负责人，设定计划日期
  • 任务执行 — 负责人按检查项逐项填写结果，系统自动计算完成进度
  • 巡检结果 — 查看历史巡检结果，统计通过/失败/警告项目数
  • 巡检计划 — 以日历视图查看巡检任务排期
10.2 工单管理
  • 创建工单 — 填写标题、描述、类型（故障/服务请求/维护）、优先级、关联设备
  • 工单流转 — 支持分配、处理、解决、关闭、重新打开等状态流转
  • 工单模板 — 预设工单模板，快速创建标准工单
  • 工单分类 — 自定义工单分类，便于统计和筛选
10.3 变更管理
  • 变更请求 — 创建变更申请，填写变更内容、影响范围、实施方案、回退计划
  • 变更审批 — 支持审批流程，记录审批意见
  • 变更日历 — 以日历视图展示计划中的变更
10.4 问题管理

记录和分析重复发生的故障，支持根因分析（RCA）、解决方案归档。可与关联工单联动，识别已知错误。

10.5 知识库

建立运维知识库，支持创建/编辑/发布技术文章。文章支持分类、标签、设备类型关联。支持草稿/发布/归档状态管理。

10.6 已知错误与服务目录

记录已知错误及其临时方案。服务目录定义标准服务项及预计完成时间，规范服务请求流程。

11. 报表中心

11.1 标准报表
  • 设备状态报表 — 在线/离线统计、设备类型分布
  • 设备性能报表 — CPU/内存/磁盘使用率排名
  • 接口利用率报表 — 接口流量和带宽利用率
  • 机柜利用率报表 — U 位占用率统计
  • 位置汇总报表 — 各位置的设备分布
  • 资产库存报表 — 资产类别、部门分布统计
  • 告警统计报表 — 告警数量趋势、级别分布
  • 监控覆盖率报表 — 已监控/未监控设备比例
11.2 综合报表

聚合展示设备分布、告警统计、性能数据、机柜利用率等，提供全局数据概览。

11.3 合规管理
  • 合规框架 — 定义 ISO27001/SOX/PCI 等合规框架及控制项
  • 合规证据 — 收集和管理合规审计证据，跟踪通过/未通过状态
  • 合规报告 — 按框架生成合规达标率报告
11.4 报表分发

创建定时分发任务，按 Cron 表达式自动生成并通过邮件/Slack/Webhook 发送报表。

11.5 趋势预测

基于历史数据生成指标趋势图表，辅助容量规划。

11.6 管理驾驶舱

面向管理层的全局数据看板，支持自定义仪表板布局。

12. 系统配置

12.1 系统设置

配置系统名称、Logo、会话超时时间、密码策略等全局参数。

12.2 SNMP 设置

配置默认 SNMP 参数（版本、团体字、超时时间、重试次数），用于设备监控和拓扑发现。

12.3 凭证管理

管理 SSH/Telnet/API 登录凭证，支持按设备类型分组管理，用于自动采集和巡检。

12.4 网络发现配置

配置 IP 扫描范围、调度计划，自动发现新设备并登记。

12.5 告警设置

配置 SMTP 邮箱（发件人地址、服务器、端口、加密方式）、企业微信机器人 Webhook、Slack Webhook、通用 Webhook，支持测试发送。

12.6 用户与权限
  • 用户管理 — 创建/编辑/禁用系统用户
  • 角色管理 — 定义管理员/操作员/普通用户/查看者等角色
  • 权限管理 — 细粒度的模块级权限控制（view/edit），覆盖设备、资产、监控、运维、报表等所有模块
12.7 配置基线

捕获设备配置快照作为基线，自动检测配置漂移（Config Drift），记录配置版本历史，支持配置差异对比。

12.8 合规策略

定义合规检查策略（安全/网络/系统类别），按计划或手动执行合规检查，生成合规报告。

12.9 审计日志

记录所有用户操作日志（创建/修改/删除），支持按时间、用户、操作类型检索。

12.10 备份与恢复

支持系统配置的备份与恢复，可下载备份文件。

13. 常见问题

进入 设备管理 → 设备列表，点击"添加设备"按钮填写表单。也可通过"网络扫描"功能自动发现设备后导入，或使用"批量导入"功能上传 Excel 文件。

首先确认设备已配置监控（设备详情 → 监控配置），确保启用了 Ping 或 SNMP 采集。检查设备是否在线、SNMP 团体字是否正确。采集任务每 30 秒执行一次，新配置的设备需要等待下一次采集周期。

第一步：进入 配置管理 → 告警设置，配置 SMTP 邮箱或企业微信/Slack Webhook。第二步：进入 告警管理 → 告警规则，创建告警规则并关联通知渠道。保存完成后点击"测试发送"验证配置是否正确。

先创建巡检模板（运维管理 → 巡检模板），定义检查项目。然后进入 巡检任务 → 新建巡检任务，选择模板、填写任务信息、指派负责人。负责人登录后即可执行巡检并录入结果。

进入 资产管理 → 资产盘点 → 创建盘点任务，选择盘点范围（按位置/部门）。系统自动生成盘点明细清单。盘点人员在现场逐项核对，录入盘点结果（一致/差异/缺失/损坏）。全部完成后生成盘点报告，查看差异分析。

进入 配置管理 → 角色管理，创建角色并勾选该角色拥有的权限（每个模块分 view/edit 两级）。进入 用户管理，为用户分配角色。系统预置了管理员、操作员、普通用户、查看者四个默认角色。

Cron 表达式格式为"分 时 日 月 周"，例如："0 8 * * 1"表示每周一早8点，"*/30 * * * *"表示每30分钟，"0 9 1 * *"表示每月1日上午9点。在报表分发任务的 Cron 字段中使用。
